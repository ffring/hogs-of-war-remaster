# Подготовь этот Mac к сетевому тесту Hogs of War

Ты работаешь на Mac второго игрока. Денис будет ведущим на другом Mac, мы находимся в разных местах. Подготовь подключение и диагностику автономно. Сначала определи macOS, процессор и текущее состояние установки. Результат — готовый клиент и короткий отчёт для Кодекса Дениса. Полный матч между двумя компьютерами ещё не подтверждён.

## Подготовка

Источник проекта: https://github.com/ffring/hogs-of-war-remaster
Сначала прочитай docs/network.md. Если приложение уже подготовлено, сохрани его рабочее состояние. Для чистой установки используй Hogs-of-War-Mac-Setup.pkg из релиза v0.5.0-test, SHA256 c36ed34951141e9443eb04c21f4a57bb855c22ba3424ab236e4d7cffc0c64d67. Установщик требует macOS14.6+. Он готовит собственную Steam-копию, не содержит игру и не включает экспериментальную мышь.

Установи приложение Hogs of War Online, укажи установленную Steam-копию или помоги скачать её через встроенную кнопку. Пароли и Steam Guard пользователь вводит сам. Нажми «Подготовить сетевой режим» и дождись успешного результата. Прежде чем повторять подготовку, проверь журнал ошибки. Исходники и сетевой помощник: work/multiplayer/mac. Не копируй Windows DLL с компьютера Дениса.

Для стандартной установки приложение — /Applications/Hogs of War Online.app, состояние — ~/Library/Application Support/Hogs of War Online, prefix — подпапка prefix, игра — prefix/drive_c/HogsofWar. Проверяй существование, не подставляй эти пути в другую установку. В Mac-установщике 0.5 для сети нужен marker prefix/.hogs-directplay-v1 и native x86 dplayx.dll/dpwsockx.dll. Legacy-маркер старого Mac Дениса здесь не используется.

Установи Tailscale из официального источника https://tailscale.com/docs/install/mac. Пользователь проходит системные разрешения и вход сам. Подключите оба Mac к одному согласованному tailnet под собственными аккаунтами. Если Tailscale уже используется для другой сети, согласуй с пользователем нужную сеть, сохрани существующие настройки. Для этого теста не нужны exit node, subnet router или публичный сервер. Адрес ведущего запроси у пользователя один раз, когда остальная подготовка закончена.

## Проверка связи и отчёт о готовности

Узнай свой Tailscale IPv4. Сохрани локально результат tailscale ping --c 3 HOST_IPV4 и обычного ping -c 3 HOST_IPV4. Отметь direct или relay; ping сам по себе не доказывает, что DirectPlay работает. Отчёт должен включать только эти два игровых узла, без списка остальных устройств и аккаунтов.

До согласованного запуска пробы сообщи READY: macOS/CPU, приложение, путь игры, готовность native DirectPlay, свой IPv4, достижимость хоста, SHA256 warhogs_.exe, отсутствует ли запущенная игра. У Дениса SHA256 warhogs_.exe =32eb8c28b383d532091dcae2057d98593be4dc064f2117212a65ced41509e246, PE timestamp0x3a069f75, SizeOfImage0x15e000. При отличии сначала объясни различие, не заменяй EXE наугад.

## Согласованная проба DirectPlay

Загрузи Hogs-of-War-Network-Diagnostics-20261104.zip из того же релиза. Сверь SHA256 по docs/network-diagnostics.json, проверь содержимое SHA256SUMS.txt. Внутри — существующая x86 консольная проба и её исходник. Она не запускает игру. Инструкция запуска в README.en.md архива. Microsoft DirectPlay DLL в архиве нет.

Когда Денис сообщит, что его host-проба выдала stage=ready, выполни один join на HOST_IPV4 с timeout45, сохрани stdout/stderr и код завершения. На Mac используй Wine из соответствующего приложения и уже подготовленный prefix, рабочую папку игры, DYLD_FALLBACK_LIBRARY_PATH=<APP>/Contents/Frameworks:/usr/lib и WINEDLLOVERRIDES=dplayx,dpwsockx=n;wsock32,mswsock=b;mscoree,mshtml=, WINEDEBUG=-all,+loaddll. Значения с точкой с запятой передавай как одну строку. Не используй системный /usr/bin/env или nice перед Wine: macOS может удалить DYLD-переменную. HOGS_MAC_FOCUS_* для консольной пробы удали из окружения. Все команды выполняй с явным WINEPREFIX, без глобального wineserver-kill. Дождись завершения пробы перед игрой.

Успех пробы: оба процесса exit0 и stage=peer_exchange. Если ошибка — верни stage, HRESULT и последние строки загрузки native/builtin DLL; не повторяй вслепую. Если оба обменялись сообщениями, согласуем игровой запуск через кнопку «Играть по сети». Подключающийся выбирает Multiplayer → Network → TCP/IP и вводит HOST_IPV4; ведущий оставляет адрес пустым. Запуск — по одной копии на каждом Mac, после согласования с пользователем.

## Что вернуть после попытки

Сохрани отдельную папку network-test-<timestamp> в рабочем каталоге. В report.md укажи локальное время/часовой пояс, версии, два игровых IPv4, хеш EXE, результат ping и пробы с exitcode, этап игрового подключения и точный текст ошибки. После попытки скопируй соответствующий Logs/online.log до следующего запуска: он перезаписывается. При успешном лобби проверь по указанию пользователя старт боя и минимум по одному завершённому ходу обоих игроков. Успех probe, лобби и боя отмечай отдельно. При краше приложи только относящийся к игре crash report.

Передай отчёт пользователю, он перешлёт Кодексу Дениса. Пароли, коды, VPN-ключи, auth-ссылки, Steam config, полные Wine registry и чужие сетевые устройства в отчёт не включай. Для первого теста сохрани графику, текстуры и управление как есть. Если firewall мешает, изучи конкретную блокировку и предложи узкое правило для приложения/игрового узла; не отключай firewall целиком и не открывай роутер в интернет.
