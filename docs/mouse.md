# Управление мышью — экспериментальная версия

Готовые установщики 0.5 используют клавиатуру и не включают этот модуль. Текущий экспериментальный модуль проверен владельцем в игре: ввод приходит, однако управление камерой и стрельба ещё требуют исправления. Его текущая схема:

- Удерживайте правую кнопку и двигайте мышь для управления камерой или прицелом.
- Продолжайте держать правую кнопку, когда останавливаете мышь: режим прицеливания останется включённым.
- Отпустите правую кнопку, чтобы вернуться к обычному управлению с клавиатуры.
- Левая кнопка — штатный выстрел; для оружия с зарядом удерживайте и отпускайте её.
- F6 — необязательный переключатель модуля. На Mac может понадобиться Fn/🌐 + F6.

На Mac исправлено обновление активного окна: в реальном запуске подтверждены включение ввода в игре и его отключение после переключения в другое приложение.

В варианте с удержанием ПКМ движение обрабатывается за один игровой опрос, а режим прицеливания удерживается непрерывно. Изолированные проверки смены направления, остановки, удержания заряда и отпускания прошли. Владелец подтвердил улучшение в игре, но сообщил о непредсказуемом направлении камеры, изменении дистанции и нестабильном выстреле при удержании ПКМ. Этот результат не принят как готовое управление.

Это управление штатными цифровыми командами игры; аналоговое FPS-прицеливание здесь не заявлено. Исходники сборки и тестов описаны в BUILDING.md. Готового установщика мыши пока нет.

Целевая схема для обычной мыши: свободный обзор с поворотом персонажа и камерой за спиной, удержание ПКМ для прицеливания, ЛКМ для выстрела или заряда. Переключение прицела кликом для трекпада не используется. Исследование штатного аналогового ввода описано в [native-control-path.md](native-control-path.md); новый режим ещё не установлен.

Для следующей ручной проверки на компьютере владельца установлен [ограниченный наблюдатель](observer.md): он записывает состояние камеры, свиньи и кнопок. Текущая схема управления при этом сохранена. Готовые установщики 0.5 не изменены.
