# Управление мышью — экспериментальная версия

Установщики 0.5 используют клавиатуру и не включают мышь. На компьютере владельца установлен [эксперимент поворота персонажа](../experiments/native-body/README.md) с камерой, следующей за персонажем:

- Движение мыши по горизонтали без ПКМ поворачивает свинью; камера следует за спиной.
- ПКМ с выбранным оружием — прицеливание.
- ЛКМ — штатный выстрел; для оружия с зарядом удерживайте и отпускайте её.
- Без оружия ПКМ не включает отдельное вращение камеры.
- F6 — необязательный переключатель. На Mac может понадобиться Fn/🌐 + F6; для обычного запуска нажимать его не нужно.

Владелец подтвердил работу поворота и камеры в бою. Установленная версия добавила инверсию обеих осей прицела. Заметного усиления чувствительности владелец не почувствовал. Сетевой матч между двумя компьютерами также не проверен. Свободный вертикальный обзор без прицеливания пока не включён.

На Mac ранее подтверждены включение ввода в игре и отключение после переключения в другое приложение. Новый модуль сохраняет эту защиту. Отдельные проверки нового ввода, моста и загрузки ASI прошли; игровые функции не запускались при установке.

Исходники нового варианта находятся в `experiments/native-body`. В `src/mouse` сохранён предыдущий модуль с [наблюдателем состояния](observer.md), который использовался для диагностики. Готового установщика мыши пока нет. [Исследование штатного ввода](native-control-path.md).

## Чувствительность и направление прицела

В текущем исходном варианте `HogsMouse.ini` задаёт `NativeUnitsPerPixel=12`, `AimSensitivityPercent=300`, `InvertX=1`, `InvertY=1`. Инверсия относится только к прицелу. Настройки перечитываются не чаще раза в секунду после отпускания кнопок мыши. Нативная ось поворота ограничена ±120, а цифровой прицел — одним направлением за чтение, поэтому 3× описывает усиление малых движений, а не гарантированную максимальную скорость.

Собрана [версия с пунктом «Мышь» в меню «Настройки»](../experiments/native-menu/README.en.md). Она позволяет менять чувствительность поворота и прицела, инверсию по двум осям, сохранять настройки или выходить без сохранения. Для неё нужна текущая русская локализация. Новое меню ещё не установлено владельцу и не проверено в настоящем запуске игры. Отдельная панель Mac больше не предлагается.

У этой версии также есть защита от зажатой клавиши на штатном экране «Нажмите любую клавишу»: сначала нужно отпустить клавишу, затем нажать снова. Она действует только там, где сама игра вызывает ожидание. Плавающий пропуск экрана пока не воспроизведён с новым модулем.

Новый способ ускорения прицела оставлен экспериментальным и выключен: `LinearAimEnable=0`. Он пока ограничен одним типом оружия и не совместим с сетевым декодированием другого игрока. Установщики 0.5 его не содержат. При выключенной опции прежний предел скорости прицела сохраняется.
