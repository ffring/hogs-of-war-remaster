# Управление мышью — экспериментальная версия

Готовые установщики 0.5 используют клавиатуру и не включают этот модуль. Следующая версия мыши подготовлена для проверки:

- Удерживайте правую кнопку и двигайте мышь для управления камерой или прицелом.
- Продолжайте держать правую кнопку, когда останавливаете мышь: режим прицеливания останется включённым.
- Отпустите правую кнопку, чтобы вернуться к обычному управлению с клавиатуры.
- Левая кнопка — штатный выстрел; для оружия с зарядом удерживайте и отпускайте её.
- F6 — необязательный переключатель модуля. На Mac может понадобиться Fn/🌐 + F6.

На Mac исправлено обновление активного окна: в реальном запуске подтверждены включение ввода в игре и его отключение после переключения в другое приложение.

Рывки исправляются отдельным изменением: движение обрабатывается за один игровой опрос, а режим прицеливания удерживается всей правой кнопкой. Проверки смены направления, остановки, удержания заряда и отпускания прошли. Проверка этого изменения в самой игре ещё нужна.

Это управление штатными цифровыми командами игры; аналоговое FPS-прицеливание здесь не заявлено. Исходники сборки и тестов описаны в BUILDING.md. Готового установщика мыши пока нет.
