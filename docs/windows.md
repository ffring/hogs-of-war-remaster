# Установщик Hogs of War для Windows

Установщик 0.5 настраивает собственную Steam-копию Hogs of War (App ID 389900). Он не содержит игру, Steam-файлы, учётные данные или сохранения. Перед установкой закрой игру.

## Подготовка игры

1. Установи Hogs of War из Steam и дождись загрузки.
2. Запусти установщик и выбери папку игры, где лежит `warhogs_.exe`.
3. Нажми «Установить исправления». Установщик сверит поддерживаемую версию игры и исходные игровые архивы, затем сохранит заменяемые файлы в папке резервной копии.
4. Чтобы убрать исправления, закрой игру и нажми «Восстановить исходные файлы».

Если игра запрашивает DirectPlay, включи компонент «Устаревшие компоненты → DirectPlay» в Windows. Tailscale нужно отдельно установить на обоих компьютерах с [официального сайта](https://tailscale.com/download/windows); затем используйте адрес Tailscale для подключения по TCP/IP в игре. Установщик не меняет сетевые настройки Windows.

## HD-профиль (по желанию)

Кнопка «Установить HD-профиль» добавляет 24 текстурные страницы из игрового захвата: шесть страниц персонажей в 4× и восемнадцать страниц окружения в 2×. Для подмены используется Texture Toolkit с DDraw/D3DImm из dgVoodoo2; на Windows он передаёт рендеринг системному Direct3D 11. Игровые архивы и их UV-развёртка не меняются. Профиль покрывает только проверенные страницы, а не всю игру.

Установка профиля требует исходные игровые архивы и пустую папку `TT\inject`. Она сохраняет копии заменяемых файлов и создаёт запись для отката. Кнопка «Восстановить графику» возвращает файлы, которые были до установки профиля. Перезапусти игру после установки. Профиль ещё не проверен в полном бою на Windows.

## Статус сетевой проверки

Успешно проверен обмен DirectPlay между двумя тестовыми процессами на одном Mac. Полный матч Hogs of War между двумя компьютерами и Windows-сборка на настоящем ПК пока не проверены. Для удалённой игры обоим игрокам нужна собственная лицензия и копия игры.

## Технические сведения

- Целевая система: 64-битная Windows.
- Установщик не запускает игру автоматически.
- Tailscale не входит в пакет.
- В HD-профиле приложены лицензии и уведомление о включённых библиотеках.
